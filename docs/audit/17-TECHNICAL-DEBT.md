# 17. חוב טכני (Technical Debt)

1. **God Component**: ה-`App.tsx` הוא חוב טכני מהגבוהים ביותר במערכת. גודלו כ-2900 שורות. פיצול לקבצי Views הוא דחוף.
2. **Missing Tests**: העדר מנגנון אוטומטי לווידוא תקינות עלול לייצר регרסיות.
3. **Hardcoded API URL**: כל הקריאות לפרונטנד שולחות לבקשות בכתובות כגון `fetch('/api/gemini/chat')`. זה תקין אם מדובר בשרת אחוד, אך יוצר בעיה אם נרצה לפצל Front/Back.
4. Firebase Security Rules לא הוגדרו עדיין כחלק ממחזור החיים של הפיתוח.
