# 11. חווית משתמש, עיצוב ו-RTL

## נראות כללית ועיצוב
הממשק בנוי בעזרת Tailwind CSS ונשען על עקרונות עיצוב מודרניים (כרטיסיות מעוגלות עם רדיוס גבוה - "Pills", הצללות רכות, מעברים מבוססי Framer Motion). ניכר שימוש בתצורת Day/Night עמוקה (Dark Mode מובנה) עם שמירה ב-`localStorage`.

## התאמה לעברית (RTL)
האפליקציה מגדירה `dir="rtl"` ברמת ה-`documentElement`.
הקוד מכיל במקומות נבחרים (כמו עורך הקוד) שימוש ב-`dir="auto"` המאפשר לעורך להתאים את כיוון הטקסט לאופי השפה המוקלדת (אנגלית תיושר לשמאל, עברית לימין), שזהו צעד נכון מאוד לטובת מפתחים (שכותבים פרומפטים בדרך כלל משולבים).

## התראות (Toasts) ופידבק
- יושם מנגנון Toasts חכם המספק משוב מיידי למשתמש על פעולות (שמירה, עדכון, מחיקה).
- המנגנון כולל התראות חברתיות ("מישהו הגיב לפרומפט שלך") המבוססות על האזנה ל-Firestore (Real-time).

## Responsive Design
רוב הרשתות (Grids) במערכת מבוססות על `md:grid-cols-2` או `grid-cols-1`, וכך הן שומרות על נראות תקינה גם במסכים צרים. התפריט הראשי הופך לתפריט כפתור במובייל.
