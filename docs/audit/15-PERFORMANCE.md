# 15. ביצועים (Performance)

* **טעינה ראשונית**: Vite מאנדל קבצים ב-Chunk אחד גדול. כרגע לא בוצע Code Splitting למעט הדיפולט. המערכת זורקת שגיאה קטנה (אזהרה בבילד) שקובץ ה-JS מגיע ל-890KB דחוס (gzip). מומלץ לבצע Dynamic Imports לספריות כבדות כמו `recharts` או `reactflow`.
* **Rendering (React)**: `App.tsx` מרנדר מחדש את עצמו במלואו כמעט בכל עדכון State (שינוי תיקיה, עדכון פרומפט, בחירת פרומפט לעריכה). יש לבחון שימוש רחב יותר ב-`useMemo` או העברת ה-State ל-Context נפרד שמוזרק רק היכן שצריך.
