# 07. באגים פוטנציאליים / חובות

כרגע במצב הנוכחי המערכת עוברת Lint בהצלחה מלאה. אין קריסות (Crashes) בולטות, אך ישנם מקומות שבהם ה"צנרת" פחות אידיאלית.

**FINDING-001**: API Keys בלקוח
* **חומרה**: Low/Medium (תלוי במטרה).
* **תיאור**: בתוך הקובץ `VisualWorkflow.tsx`, מתבצעת קריאה מה-`localStorage` של `promptvault_gemini_key`. נראה שחלק מהקוד נשען על קוד הלקוח כדי להזרים מפתח לשרת במידה ורוצים. במערכת Production אמיתית המפתח תמיד חייב לשבת נטו בשרת (environment variables).

**FINDING-002**: העדר Pagination לנתוני קהילה.
* **חומרה**: Low.
* **תיאור**: ב-`CommunityView`, הבקשות ל-Firebase מביאות את *כל* הפרומפטים או אוסף גדול של מסמכים. עם גדילת הקהילה, הדבר ייצר חסימה ובעיות ביצועים. נדרש מימוש `limit` ו-`startAfter`.
