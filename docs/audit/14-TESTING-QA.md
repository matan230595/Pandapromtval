# 14. תוכנית בדיקות (Testing & QA)

בשלב זה **אין בדיקות אוטומטיות (Unit/E2E)**.

## מצב קיים
* **Static Typing**: המערכת עוברת Type checking בעזרת הפקודה `npm run lint` (שהוגדרה לרוץ כ-`tsc --noEmit`). מונע שגיאות הקלדה וחיבורי ממשקים שגויים.
* **Build Test**: הבנייה (`vite build` + `esbuild`) עוברת בהצלחה ומוודאת שכל התלויות זמינות.

## צרכים עתידיים
* Unit Tests למנגנוני חישוב שונים (כגון חישובי ROI בדאשבורד).
* Integration Tests: כלי לבדיקת תקינות הקריאות מול Firebase (עם אמולטור Firebase) למניעת הרס נתונים.
* E2E (Playwright / Cypress): בדיקת הפלואו המלא מרגע כניסת משתמש ועד שמירת הפרומפט בענן.
